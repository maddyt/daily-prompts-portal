# Contributing to Daily Prompts Portal

Thank you for your interest in contributing! Here's how you can help:

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/daily-prompts-portal.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Install dependencies:
   ```bash
   cd frontend
   npm install
   ```

## Development

### Running Locally

```bash
cd frontend
npm run dev
```

Visit `http://localhost:3000` to see your changes.

### Code Style

- Use TypeScript for type safety
- Follow ESLint configuration
- Format code with Prettier (configured in project)

### Testing

```bash
cd frontend
npm run build  # Verify build succeeds
```

## Submitting Changes

1. Push to your fork
2. Create a Pull Request with a clear description
3. Link any related issues
4. Ensure CI passes (linting, build)

## Pull Request Guidelines

- Provide a clear description of changes
- Include screenshots for UI changes
- Reference issue numbers with `fixes #123`
- Keep PRs focused on a single feature/fix
- Update documentation if needed

## Reporting Issues

- Check existing issues first
- Use bug report template for bugs
- Use feature request template for enhancements
- Include environment details

## Questions?

Feel free to open a Discussion or Issue!

Thank you for contributing! 🙏
